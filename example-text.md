# Some kind of second inciting incident

The API documentation is not that easy to search, and I had to supplement it

# A quick ending

I decided to not use a second pane to display the information. It allows
me to use a narrower window for typing (I hard wrap at 80 columns) and all the
information I need is available with a TAB, which is quicker than switching
panes
